# 💫 About the project:
CustomRom.world is an open source Android Rom archive and library open to everyone. It's made to make finding your next Rom easily, and with the right resources. Users are free to upload (with approval) and can unlimitedly download from our library all sorts of roms. GSIs, Officials, Unofficials, Auto-Installers, etc.

# ⚒️ My work
I put a lot of work into this project. Hand writing 500+ pages of custom roms onto the website, for everyone to download for free. Sharing, liking, or using the website is an deeply appreciated sign of support for me! To be transparent, the website itself was made with the help of Lovable; as I'm not specialized in web coding and/or designing. Nonetheless, the project took time and sweat so supporting it would make me really happy!
