# 💫 About the project:
CustomRom.world is an open source Android Rom archive and library open to everyone. It's made to make finding your next Rom easily, and with the right resources. Users are free to upload (with approval) and can unlimitedly download from our library all sorts of roms. GSIs, Officials, Unofficials, Auto-Installers, etc.
